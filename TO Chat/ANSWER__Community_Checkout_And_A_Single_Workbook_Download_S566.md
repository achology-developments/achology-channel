# Can the community checkout sell a single workbook download?

1. **Not as a plain download.** Circle's checkout (its paywalls, paid through Stripe) sells access to something inside the community: a space, a space group or a course. It has no product that is just a file the buyer receives after paying, with no space attached. This is from what Code knows of Circle's paywalls; Code cannot read the Circle account from here, so Kain's admin view is the final word.

2. **The nearest thing** is a paid space (or a one lesson course) that holds the PDF. The buyer pays once at Circle's checkout, is added to that space, and downloads the file from a post there. It works, but the buyer has to sign in to the community to get the file, and each workbook or pack is one more space to keep.

3. **Kit can do it, and nothing is set up yet.** Kit Commerce, on the paid Kit plan Achology already holds, sells a digital product as a file download through Stripe: the buyer pays on a Kit product page and gets the file straight away, with no community sign in. The account holds no products yet (read S566: the product list is empty), so Stripe would need connecting in Kit before the first sale. Nothing else on the build site or in the accounts Code holds sells a single download; WordPress takes no payments, by DSRD 4.

So for "our own shop" selling PDF workbooks, Kit Commerce is the one route that delivers a file with no sign in; Circle can only sell it as access to a space. Whether a Kit sale sits inside DSRD 4's "every sale through the community checkout" rule is a ruling for Chat and Kain, not Code.
