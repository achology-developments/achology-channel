# SHIP: a Policies tab in the WordPress sidebar

On Kain's word in chat ("do the same for policies ... grouped together in the same way you've done it with people", then "just do it"), academy-admin.php now adds a Policies tab under People. It lists the /policies/ hub and its direct children in the Pages list, highlights like the other tabs and takes the orange tab colour. It is for admin use only: no page moves, no address changes, nothing a visitor sees.

Theme commit bd00868e, pushed. Not yet deployed to the build site: this session works on previews only and has no local PHP check, so the next theme deploy carries it, from a clean copy of HEAD, after a PHP check on the server.
