# ASK: the Events page: the words for the event ticket, and four small facts

From Code, theme session S529, 16 November 2026. Kain asked for this request in the sitting: "we actually need some editorial, like an editorial request made to give to chat, because ... when those events are essentially clicked on, we need there to be some sort of pop-up, or it looks like a ticket. We need something to pop up that explains what the event actually is."

Read from the vault first: none fit that Code knows of; the governing documents are the Events page spec (sections 5.4, 7 and 10) and REF 1 (sections 4.1 to 4.3 and its two appendices).

## What Code looked at first, and what it did not answer

- The spec's section 7.1 gives each of the nineteen entries its day, UK time, Circle name, host and access. It gives no length and no description.
- REF 1 section 3.3 gives 90 minutes for the VALT types and nothing for any other event. Its appendices hold the 22 locked descriptions, with dashes in them, not yet copy edited for the public site (the spec's section 10 makes that edit yours).
- So the preview shows a length on eight entries only, and no description on any.

## 1. For each of the nineteen entries in section 7.1

One row each, please, with:

1. The Event Kind it belongs to (one of REF 1's 22), or "no kind". Code's reading of the brackets in section 7.1 is in build.py in the preview folder; say where it is wrong. Three need your call: the four free Modern Applied Psychology events, Achology Office Hours with Karen Ramsay, and Code of Character & Conduct Training (Community Learning Event).
2. Its short description for the pop-up: the About This Event paragraph of its kind, copy edited (spec section 5.4, item 3), or its own short description where it has no kind.
3. Its length in minutes.
4. How often it runs, where it is not every week. Code has drawn The Wiser Woman Project as "Every other week" from REF 1's "Bi-Weekly" and Circle's "1st and 3rd Thursday of every month": confirm or correct.
5. Its host line as the page may say it (the spec says no host is named by person), and its credit line, if any.

## 3. The month (added later in the same sitting)

The spec's section 7.1 gives the week, and one line under its table names what else is on Circle's month view. That line is not enough to place three of them, so the month in the preview is short of them:

1. The first Tuesday's event, whose name is cut off in the spec ("How to Set Yours..."): its full name, its time, and how often it runs.

3. The Achology Book Club: only one date is given (Sunday 29 November). How often it runs and its time. It is the only weekend event; say whether the month should carry a weekend column for it.
