# RULING: Code writes a one-rule change Kain orders into the document that owns it (Kain, Session 460)

Kain, asked "May Code write a rule you order in its sitting straight into its spec, with Chat reading it after?", answered: "Yes, Code writes it".

**What changed, as a replacement, not an added rule.**
- The Harness, Rule 8: "Code never edits a DSRD" now carries one route: a one-rule change Kain orders in Code's sitting, Code writes straight into the DSRD or spec that owns it, naming his words, the date and its session in that document's change register line, and files a NOTE in TO Chat the same session; Chat reads it at its next open and settles anything that conflicts.
- The Harness, Rule 14: a ruling is still filed the same session; for a one-rule change, Code writes it home itself under Rule 8's route and files a NOTE in place of the RULING.
- The Shared Rules, section 4: the DSRDs are never mirrored or copied; Code edits one only by that route.

**What does not change.** Content drafting stays with Chat. A ruling that needs more than one rule, a new section, or a choice between two defensible wordings still travels to Chat as a RULING file. Code still never edits The Harness or The Shared Rules.
